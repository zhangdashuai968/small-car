## 异常记录

### 异常 1：RGB 摄像头节点 gemini 崩溃
- **症状**：`/camera/rgb/image_raw` 无发布者，`/camera/gemini` exit code 255
- **排查路径**：rosnode info → 检查 gemini 日志 → fuser 检查 USB 设备 → 发现 PID 5111 僵尸进程
- **根因**：上一次会话遗留的 astra_camera/camera_node (PID 5111, 启动于 21:23) 占用 USB 设备 2bc5:0511，当前 gemini 无法打开设备
- **修复**：`kill -9 5111` → `rosrun astra_camera camera_node /camera/image_raw:=/camera/rgb/image_raw __name:=gemini __ns:=camera`
- **教训**：roslaunch 不会自动清理上一次会话的进程，再次启动前应 `pkill -f ros`

### 异常 2：vl_locate 未编译
- **症状**：`rosservice call /vlm_detection` → `Unable to load type [vl_locate/GetObject]`
- **根因**：vl_locate 包从未 catkin_make 编译过
- **修复**：`catkin_make --only-pkg-with-deps vl_locate`

### 异常 3：API Key 三连 403
- **症状**：dashscope SDK MultiModalConversation.call() 返回 status_code=403，三个 key 均失败
- **排查路径**：
  1. Python requests 直调 OpenAI 兼容端点 → HTTP 200（key 有效）
  2. Python requests 直调 DashScope 原生端点 → HTTP 200（key 有效）
  3. dashscope SDK 测试 → 403（**SDK 有 bug**）
  4. OpenAI SDK 测试 → qwen-turbo 200, qwen-vl-max-latest 403, qwen-vl-max 200
- **根因**：(a) dashscope 官方 Python SDK 返回假的 403；(b) 该 key 只有 qwen-vl-max 和 qwen-vl-plus 权限，无 qwen-vl-max-latest
- **修复**：rosparam set mode=openai, model=qwen-vl-max，重启 vlm_detection_node
- ⚠️ **技术债（未修复）**：
  - `server.py` 第36行默认值 `qwen-vl-max-latest` → 应为 `qwen-vl-max`
  - `vlm_params.yaml` 第16行 `qwen-vl-max-latest` → 应为 `qwen-vl-max`
  - `vl_locate.launch` 中 `<param name="mode" value="dashscope"/>` → 应改为 `openai`
  - **当前靠 rosparam 运行时覆盖撑着，节点重启即复现 403。下次上车第一件事改这三个地方。**

### 异常 4：六点巡逻 wp3 ABORTED（重要）
- **症状**：wp2→wp3 过程车在原地打转 59s 后 ABORTED，用户观察"原地打转找不到路"
- **排查路径**：
  1. Bag 分析 AMCL 时间线 → wp3 开始时定位准确（距 wp2 <0.05m）
  2. Bag 分析 cmd_vel 三阶段 → 前段缓慢(0.016m/s)→中段加速(0.040m/s)→末段纯旋转(0.97rad/s)
  3. Bag 分析 /scan → **前方 0.136m / 左侧 0.137m / 右侧 0.136m，仅后方 1.37m 畅通**
  4. **排除 EKF 漂移**：AMCL 在 wp2 处误差 <0.05m，定位不是问题
  5. **此前错误诊断为"EKF 融合 IMU 偏航漂移污染 AMCL"——被用户纠正**
- **根因**：点位 wp2 物理位置处于狭小空间，车到达后三面被障碍物围住（~0.14m），TEB 局部规划器找不到无碰轨迹，只能原地旋转寻找通路，oscillation_timeout 触发 ABORTED
- **影响**：wp4-wp6 未执行
- **待解决**：wp2 后移或增加初始倒车动作，或调整 costmap 膨胀半径
