# 2026-10-28 轮编码器精度测试（隔离测量，第 1 推）

## 目的
单独测轮编码器测距精度，不掺 IMU / EKF / amcl——为 `linear_scale` 定标提供原始误差数据。

## 环境
- 车：Jetson Nano（ssh cc = abot@10.54.158.46），车上为 2024-11 原厂世代代码，`linear_scale=1.0`（未修正原值）
- 最小链路：`roscore` + `rosrun rosserial_python serial_node.py _port:=/dev/abotbase _baud:=115200` + `rosrun abot abot_base_node`（节点名 /riki_base_node）
- 无 IMU、无 madgwick、无 EKF、无 TF——读 `/raw_odom` 即纯轮编码器里程（abot_base_node 航向亦为轮速自积分，与 IMU 零耦合，见 abot_base.cpp:50-57）
- 数据流：/raw_vel 29.4Hz，/raw_odom 29.2Hz
- 记录：`rostopic echo -p /raw_odom/pose/pose/position` → 车上 /tmp/enc_test/push1.csv，已取证至本目录

## 方法
电机不动，人工手推小车直线约 20cm（odom 负 x 方向），卷尺实测行程，对比 /raw_odom 位移。

## 数据（push1.csv，29Hz，8739 行）
- 静置段 ~233s：x 恒为 0.000000——**静止零漂移**（serial.log 中 Arduino "Encoder LR/RR/RF/LF" 非零计数未转化为里程，无实际影响）
- 起点：x=0.000000, y=0.000000
- 终点：x=-0.198161, y=+0.003681
- 编码器测距 D_odom = √(0.198161² + 0.003681²) = **0.19820 m**
- 人工实测 D_real = **0.21 m**

## 结果
- 编码器读数为真实行程的 **94.4%，欠报 5.6%**
- 按本次推算 `linear_scale = 1.0 × 0.21/0.19820 ≈ 1.060`

## 误差带与保留意见
- 20cm 级基线太短：人工读尺 ±0.5cm 即 ±2.4% 误差带，本次 5.6% 超出但置信度有限
- 单次测量未复测；正式定标建议 2m×3 次取中值，再写入 linear_scale
- y 向偏 0.37cm：手推歪斜或麦轮侧向轮感，量级可忽略

## 车上遗留
- 测试节点仍在车后台运行（roscore + /serial_node + /riki_base_node），echo 记录器仍写 /tmp/enc_test/push1.csv——复测可直接推，或告知后清理

## 汇总结论
- **欠报高度一致：4.96%–5.62%，极差仅 0.66 个百分点**——系统性比例误差（轮径/齿比常量），非随机噪声
- 20cm 短基线推与 50cm 组吻合，短基线担虑解除，数据可信
- scale 汇总：3×50cm 总和法 **1.0555**，均值 1.0554，4 组总和 1.0559——**推荐 linear_scale = 1.055**
- 静置零漂移维持 0

## 附加观察：y 向累计漂移
- Δy 逐推 +0.0037 / +0.0169 / +0.0209 / +0.0386，累计 +0.080m（占总行程 4.9%），且逐推增大
- 可能原因：手推方向逐次偏斜；或 abot_base_node 轮速自积分航向在手推中漂移，使后续直推投影进 y
- 对本次 scale 标定无影响（位移取 2D 模长），但**若为航向积分漂移，正式导航时轮速航向不可信的判断再次得到印证**（EKF 配置已排除轮速 yaw，设计正确）

# 电机工况标定（22:12~22:3x，推翻手推结论）

## 过程
- 闭环脚本 drive50.py（0.1/0.15 m/s 巡航 + 0.03 爬行 + 位移闭环 + 零速流停车 + 三看门狗）电机驱动，用户卷尺实测对比
- 第一轮发现 odom 报 50.6 实走 47.4 → 手推标定的 1.055 对电机工况多报 ~6%；三轮换算验证后回调 **1.055 → 1.0**，复测 5 轮

| 7 | 0.15 | 51.24 | 50.5 | +1.5% |

## 结论
- **电机工况 scale=1.0 定版**：8 轮均值 +1.05%，带宽 −0.9%~+2.2%，0.1 与 0.15 m/s 无显著差异（低速打滑对速度不敏感）
- **手推标定作废**：手推存在系统性欠转（外力+齿轮箱阻力致轮子微滑移），1.055 是在给手推滑移买单；电机驱动轮子主动转，原厂 1.0 本来就准
- 若追求极致可再调 0.99（把 +1% 均值归零），但 ±2% 带宽下收益有限，暂不折腾
- 刹车过冲波动 0.04~2.49cm（固件减速斜坡，疑随电压下降变大）——不影响 odom 与物理的一致性，只影响"精确停在某点"，后续可加提前触发补偿
