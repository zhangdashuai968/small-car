## 异常记录

### 异常 1：navigate.launch 重启后 move_base action server 不可用

- **症状**：脚本卡在 `wait_for_server()`，日志只有 rosdep 警告
- **排查过程**：
  1. rosnode list 显示 move_base/amcl/map_server 存在 → 查 ps 找不到对应进程
  2. roslaunch 被杀后 zombie 节点残留，roscore 未清理注册
  3. 新 launch 起的 lidar 节点与旧 zombie 冲突 (new node registered with same name)
  4. scan 无数据 → AMCL 不工作 → map 帧不存在 → move_base 永远等不到 transform
- **根因**：杀 roslaunch 后旧节点进程残留（nohup 启动），新 launch 同名冲突
- **修复方式**：killall -9 杀所有进程 + 重启示 roscore，按顺序重启四个 launch
- **教训**：清进程不要只杀 roslaunch，要杀对应的可执行文件进程

### 异常 2：killall 杀不掉 nohup 启动的进程

- **症状**：多次 killall roslaunch 后 rosnode list 仍有节点
- **根因**：nohup 启动的进程父进程被杀后变为孤儿但继续运行，roslaunch wrapper 脚本被杀但实际 ros 节点进程名不包含 "roslaunch"
- **修复方式**：killall 直接按可执行文件名（move_base/amcl/map_server/rosbag/record）杀
