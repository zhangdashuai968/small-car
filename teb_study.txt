═══════════════════════════════════════════════════════════════
              TEB 全向底盘参数 — 数学原理白话版
═══════════════════════════════════════════════════════════════

▸ 总目标函数（先记住这个框）

    优化器在干一件事：最小化总代价

        f(τ) = Σ γ_k · Σ e_{k,i}²(τ)
               k        i

    翻译：把所有"不满意的事"（超速、离墙太近、走太慢...）
    各算一个误差 e，平方后乘权重 γ，全加起来。
    谁的权重高，优化器就先哄谁。


═══════════════════════════════════════════════════════════════
一、Trajectory（弹性带结构）
═══════════════════════════════════════════════════════════════

  ■ dt_ref = 0.2
    期望时间步长 0.2 秒。
    弹性带上相邻关键点之间理想间隔 0.2 秒，优化器会自适应插点/删点：
      · ΔT_i > 0.2 + hysteresis → 插新点（太稀疏，加密）
      · ΔT_i < 0.2 - hysteresis → 删点（太密，没必要）
    💬 理想情况下每 0.2 秒经过一个姿态点，点太疏就补，太密就删。

  ■ dt_hysteresis = 0.1
    时间步长"死区" 0.1 秒。
    配合 dt_ref=0.2：
      · ΔT_i > 0.3 才插入新点
      · ΔT_i < 0.1 才删除点
    💬 防止 0.19 秒和 0.21 秒之间来回振荡。
       类比：空调设 26°C，到 26.1°C 不马上转，偏离 1°C 才动作。

  ■ max_global_plan_lookahead_dist = 3.0
    前瞻距离 3 米。
    只看全局路径上未来 3 米的片段来优化，不看整条路。
    💬 远处信息变动快，看了也白看——反正每 0.02 秒重新规划一次。

  ■ global_plan_viapoint_sep = -1
    沿途点采样间距，-1 表示禁用。
    💬 如需启用（比如设 0.5），则全局路径上每 0.5 米取一个途经点，
       用弹簧效应把弹性带拉向全局路径。


═══════════════════════════════════════════════════════════════
二、Robot（机器人物理极限）
═══════════════════════════════════════════════════════════════

    这些参数定义了惩罚函数"墙壁"的位置，公式模式都一样：

                 ⎧ 0              没靠近墙
        e(z) =   ⎨
                 ⎩ z - z_max + ε  快要撞墙了

  ── 速度上限 ──────────────────────────────────────────────

  ■ max_vel_x = 0.8         前进速度上限

        惩罚函数：
                 ⎧ 0                          |v_x| ≤ 0.8 - 0.1
        e_vx =  ⎨
                 ⎩ |v_x| - 0.8 + 0.1         超了

        其中  v_x = |d_i|·cos(α_i) / ΔT_i
              （位移在机头方向的投影 ÷ 时间）

    💬 前进速度超过 0.7 m/s（= 0.8 - 0.1 缓冲）开始惩罚。
       优化器想降惩罚，要么拉长 ΔT（走慢点），要么缩短位移（改路径）。

  ■ max_vel_x_backwards = 0.2   后退速度上限
    💬 倒车看不到后面，限速更严，最高只允许 0.2 m/s。

  ■ max_vel_y = 0.8         侧移速度上限
        v_y = |d_i|·sin(α_i) / ΔT_i
    💬 麦轮能横着走，但侧移速度也别超 0.8 m/s。
       这个参数对麦轮很重要——侧移是麦轮的特色能力。

  ■ max_vel_theta = 1.2     角速度上限
        ω_i = (θ_{i+1} - θ_i) / ΔT_i
    💬 原地旋转最快 1.2 rad/s（约 69°/s），转太快传感器数据会糊。

  ── 加速度上限 ────────────────────────────────────────────

  ■ acc_lim_x = 1.5          纵向加速度上限
        a_x,i = (v_x,i - v_x,i-1) / ½(ΔT_{i-1} + ΔT_i)
    💬 前后两段速度变化不能太猛，最大 1.5 m/s²。
       加速度惩罚连接三个连续姿态点 + 两个时间间隔，在图优化里是一条"超边"。

  ■ acc_lim_y = 1.5          侧向加速度上限
    💬 侧向加速也不能太猛，同理 1.5 m/s²。

  ■ acc_lim_theta = 2.5      角加速度上限
    💬 旋转加速最快 2.5 rad/s²，防止"突然狂转"。

  ── 转弯半径 ──────────────────────────────────────────────

  ■ min_turning_radius = 0.0   最小转弯半径
        R_i = |v_x,i| / |ω_i| ≥ R_min
    💬 全向底盘设为 0，因为麦轮可以原地旋转（转弯半径为零）。
       如果是阿克曼底盘（汽车），这个值就不是零了——车打的最小弯有限。


═══════════════════════════════════════════════════════════════
三、Footprint Model（机器人外形）
═══════════════════════════════════════════════════════════════

  ■ footprint_model = polygon
    vertices = [[-0.12,-0.12], [-0.12,0.12], [0.12,0.12], [0.12,-0.12]]
    💬 机器人是一个 24cm × 24cm 的正方形。
       障碍物距离从多边形边缘算，不是从中心点算。


═══════════════════════════════════════════════════════════════
四、Goal Tolerance（目标点容差）
═══════════════════════════════════════════════════════════════

  ■ xy_goal_tolerance  = 0.08    位置容差 8 cm
  ■ yaw_goal_tolerance = 0.1     角度容差 0.1 rad（约 5.7°）
    💬 车到离目标点 8 cm 以内、朝向偏差 < 5.7° 就算到达。


═══════════════════════════════════════════════════════════════
五、Obstacles（障碍物）★ 重点
═══════════════════════════════════════════════════════════════

  ■ min_obstacle_dist = 0.25
    最小安全距离 25 cm（核心惩罚！）

                 ⎧ 0                          d ≥ 0.25 + 0.1
        e_obs =  ⎨
                 ⎩ (0.35 / d)^(4/2) - 1       0 < d < 0.35

    💬 机器人边缘离障碍物不到 0.35 m（= 0.25 + 0.1 缓冲）就开始惩罚。
       惩罚是 1/d 型——距离趋近零时惩罚趋近无穷大，形成"硬壁"效果。
       不可能出现"优化器算出来穿墙更划算"这种离谱事。

  ■ inflation_dist = 0.6
    膨胀层半径 60 cm

                 ⎧ 0                        d ≥ 0.6
        e_inf =  ⎨
                 ⎩ 0.2 · (0.6 - d)          0.25 ≤ d < 0.6

    💬 在安全距离 25 cm 外再画一个 60 cm 的"警戒圈"。
       进入警戒圈有轻微惩罚（权重 0.2，很低），离墙越近惩罚越大，
       但远没有真正逼近安全距离时那么猛烈。
       效果：有空间时机器人自觉走走廊中间，不贴墙。

  ■ obstacle_cost_exponent = 4
    障碍物代价指数 p = 4，上面公式中 (1/d)^(p/2) = (1/d)²。
    💬 p 越大"墙壁越硬"——靠近时惩罚上升越陡。
       p=4 是经验值，足够硬又不至于让优化器数值不稳定。

  ■ obstacle_poses_affected = 15
    每个障碍物只影响最近 15 个弹性带节点。
    💬 远处的障碍物跟弹性带中间段无关，不建约束边，省计算量。


═══════════════════════════════════════════════════════════════
六、Optimization（优化权重）★ 最关键的一组
═══════════════════════════════════════════════════════════════

    以下 γ_k 就是总目标函数 f(τ) = Σ γ_k·Σ e² 里的权重。

  ─────────────────────────────────────────────────────────
  权重参数                      值      在优化器眼中的含义
  ─────────────────────────────────────────────────────────

  ■ weight_optimaltime         100     🏃 快跑！越快越好

        f_time = 100 · Σ ΔT_i²

    💬 TEB 核心！每个时间间隔 ΔT 平方后乘 100 加入代价。
       优化器想降代价就必须缩短每段时间 → 跑得快。
       但不能无限缩短，因为 v = d/ΔT 增大会触发速度上限惩罚。
       "时间短" vs "速度不超限" 的拉锯 → 时间最优轨迹。
       权重 100，最高优先级之一。

  ─────────────────────────────────────────────────────────

  ■ weight_obstacle            100     🧱 别撞！离墙远点

        f_obs = 100 · Σ e_obs²

    💬 和 time 同级！"别撞墙"和"跑得快"一样重要。
       优化器同时被两个 100 的力量拉扯——一边赶时间，一边躲障碍。

  ─────────────────────────────────────────────────────────

  ■ weight_max_vel_y            10     ↩  少侧移，走正路

        f_vy = 10 · Σ e_vy²

    💬 侧移权重 10（比前进的 2 大 5 倍）。
       麦轮虽能侧移，但侧移时四个轮子斜着转，精度差、磨损大。
       "劝阻"侧移——能用前进解决就不侧移。

  ─────────────────────────────────────────────────────────

  ■ weight_max_vel_x             2     前进可以，别太猛

        f_vx = 2 · Σ e_vx²

    💬 权重 2，比较低。允许偶尔超一点速，全向底盘灵活。

  ─────────────────────────────────────────────────────────

  ■ weight_max_vel_theta         1     转快点问题不大

  ─────────────────────────────────────────────────────────

  ■ weight_acc_lim_x              1
    weight_acc_lim_y              1     加速度约束，中规中矩
    weight_acc_lim_theta          1

  ─────────────────────────────────────────────────────────

  ■ weight_kinematics_nh         1     全向，侧移一下也行

        f_nh = 1 · Σ (|d_i|·sin(α_i) / ΔT_i)²

    💬 差速底盘这个权重设 1000（≈ 硬约束，侧移绝对不行），
       全向底盘只设 1（轻微劝阻侧移但不禁止）。
       效果：偶尔侧移也行，但别过分。

  ─────────────────────────────────────────────────────────

  ■ weight_viapoint              1     跟着全局路径走

        f_via = 1 · Σ |s_i*^xy - p_j|²

    💬 像弹簧一样把弹性带"拉向"全局路径。
       权重 1 不大，可以为了避障偏离全局路径。
       多点导航时应该加大（比如 5~10）。

  ─────────────────────────────────────────────────────────

  ■ weight_kinematics_turning_radius   1   转弯半径约束
    💬 全向底盘 min_turning_radius=0，此约束不起作用。
       权重留着，万一以后换底盘。

  ─────────────────────────────────────────────────────────

  ■ weight_inflation            0.2    有空地就走中间
    💬 权重很轻，膨胀层只是"建议"走中间，不是硬要求。

  ─────────────────────────────────────────────────────────

  ■ weight_kinematics_forward_drive   0.1   倒车也没事

        e_fwd = { 0         v_x ≥ 0
                { -v_x      v_x < 0

    💬 权重只有 0.1，几乎不限制后退。全向底盘后退也很灵活。
       差速底盘就得设大些。

  ─────────────────────────────────────────────────────────

  ■ weight_shortest_path         0     绕一点路无所谓

        f_path = 0 · Σ |d_i|²

    💬 设为 0，不在意路径最短。
       时间最优（权重 100）已间接让路径不绕远——
       绕远路 → 耗时更长 → 时间惩罚更大。

  ─────────────────────────────────────────────────────────

  ■ penalty_epsilon = 0.1
    惩罚缓冲区。
    💬 所有"墙壁"前塞一个 0.1 单位的缓冲垫。
       进入缓冲垫就有阻力，防止优化器在硬边界上反复弹跳不收敛。


═══════════════════════════════════════════════════════════════
七、Homotopy Class Planning（同伦类规划）
═══════════════════════════════════════════════════════════════

  ■ enable_homotopy_class_planning = true
    💬 开！障碍物把空间分成左右两条路时，TEB 默认只优化初始化的那一侧。
       开启后，同时维护最多 4 条"拓扑不同"的路径（比如左绕、右绕各一条），
       优化完后选代价最小的执行。

  ■ max_number_classes = 4
    💬 最多保留 4 条不同绕法，太多浪费算力。

  ■ selection_prefer_initial_plan = 0.9
        C_eff(τ_current) = 0.9 · C(τ_current)
    💬 正在走的路径打九折。另一条候选路径必须比当前路径好 10% 以上才切换——
       防止两条差不多的路径之间"左右横跳"。

  ■ switching_blocking_period = 0.0
    💬 切换路径后冷却期 0 秒，不锁定。需要时可立刻切换。

  ■ h_signature_threshold = 0.1
        H_j(τ) ≈ Σ (s_i^xy - o_j)⊥ · (s_{i+1}^xy - s_i^xy) / |s_i^xy - o_j|²
    💬 H-signature 是路径的"拓扑指纹"——算路径相对于每个障碍物是
       顺时针绕还是逆时针绕。两条路径 H-signature 差距 < 0.1 就算同一类，
       只保留代价最小的那条。

  ■ roadmap_graph_no_samples = 15
    💬 生成候选路径时，在自由空间随机撒 15 个采样点，
       加上起点终点构建可见性图，搜出多条不同走法。


═══════════════════════════════════════════════════════════════
八、Recovery（恢复机制）
═══════════════════════════════════════════════════════════════

  ■ shrink_horizon_backup = true
    shrink_horizon_min_duration = 10
    💬 优化不收敛时（比如窄通道挤住了），临时缩短前瞻距离——
       只看眼前一小段先走出去。撑 10 秒后恢复完整视野。

  ■ oscillation_recovery = true
    oscillation_v_eps = 0.1
    oscillation_omega_eps = 0.1
    💬 检测机器人是否在"犹豫不决"——速度正负来回切（前进 ↔ 后退），
       幅度 < 0.1 m/s。检测到后持续 10 秒就强制沿当前朝向冲出去。
       典型场景：T 字路口左转还是右转？反复摇摆。

    在安全的前提下，用最短时间到达目标。
