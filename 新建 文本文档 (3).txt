  4. scripts/auto_task_runner.py — 航线任务调度（最重要的脚本）

  不依赖 move_base，直接用 cmd_vel 原语控制底盘。

  核心逻辑：
  1. 读取 waypoints.yaml
  2. 每个点位：L 形分解（先 X 后 Y，或先 Y 后 X）→ 两段直线 + 最后原地旋转
  3. 到位后调用 /vlm_detection 服务 → 机械臂执行抓取/释放
  4. 全程保持车头朝向锁定（hold_yaw），用 K_LIN_HOLD 压制非主运动轴漂移

  关键参数（L39-49）：
  V_LIN     = 0.20   # 直线速度上限
  V_ROT     = 0.40   # 旋转速度上限
  K_LIN     = 4.0    # 线速度 P 增益
  K_LIN_HOLD = 5.0   # 非主运动轴压制增益 ← 专门压制漂移
  POS_TOL   = 0.04   # 终点位置容差 4cm

  坐标系技巧（L191-213）：frame='body' 模式直接以车头朝向为参考，避免 map 帧下 yaw 接近 180° 时方向翻转。

  5. scripts/waypoints.yaml — 航线配置

  定义了 6 个点位，3 组抓取+放置：
  pickup_grape(葡萄) → drop_center_1
  pickup_banana(香蕉) → drop_center_2
  pickup_mangosteen(山竹) → drop_center_3
  - action: grab → 到位后调用 vlm_detection → 机械臂抓取；place → 释放
  - object: 喂给 VLM 视觉定位的目标关键词
