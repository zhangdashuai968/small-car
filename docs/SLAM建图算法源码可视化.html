3.4 Lua 配置结构

Cartographer 的核心配置不在 XML/YAML，而在 .lua 文件（Google 风格）：

                    ── rplidar_lds.lua (2D 激光 SLAM) ──
include "map_builder.lua"         ← 引入 Google 默认 MAP_BUILDER 原型
include "trajectory_builder.lua"

options = {
  map_frame = "map",               ← 发布的地图坐标系
  tracking_frame = "base_footprint",   ← 跟踪的机器人坐标系
  odom_frame = "odom",              ← 里程计坐标系
  provide_odom_frame = true,          ← Cartographer 自己发 odom→map
  num_laser_scans = 1,              ← 1个单线激光
  num_point_clouds = 0,             ← 无多线点云
}
MAP_BUILDER.use_trajectory_builder_2d = true  ← 2D建图模式

── rslidar_3d.lua (3D 多线点云 SLAM) ──
TRAJECTORY_BUILDER_3D.min_range = 0.2     ← 多线雷达最近距离
TRAJECTORY_BUILDER_3D.max_range = 100.    ← 多线雷达最远距离
MAP_BUILDER.num_background_threads = 4   ← 后台线程数（Jetson: 4核刚好）
POSE_GRAPH.constraint_builder.min_score = 0.5    ← 回环匹配最低分
POSE_GRAPH.constraint_builder.global_localization_min_score = 0.55

── rslidar_3dto2dlds.lua (3D→2D 投影) ──
TRAJECTORY_BUILDER_2D.min_z = 0.3    ← 裁切高度下限
TRAJECTORY_BUILDER_2D.max_z = 1.3    ← 裁切高度上限（过滤地面+天花板）

8. 启动链路

8.1 Gmapping 建图（当前主力）

1
roslaunch abot bringup.launch
底盘驱动 + IMU + EKF（发 odom→base_footprint）+ 激光驱动（RPLidar C1）
2
roslaunch abot lidar_slam.launch
启动 gmapping（slam_gmapping.xml 配置）+ 可选 move_base
3
rosrun rviz rviz -d .../lidar_slam.rviz
观察 /map 实时构建 | 用手柄/键盘遥控小车走遍场地
4
rosrun map_server map_saver -f my_map
保存 pgm+yaml | 后续 localize.launch 加载

8.2 自动探索建图（全自动）

1
roslaunch abot auto_slam.launch
一键启动：激光 + gmapping + explore_lite（自动探索）+ move_base（导航）+ RViz（可视化）
2
⚠️ 运行条件
需要 move_base 参数完整 + 场地无障碍 + 围栏定义明确 | 30s 不动自动判负

8.3 Cartographer 建图（备用）

# 启动命令
roslaunch abot cartographer_slam.launch

# 等价于:
# 1. 启动激光驱动 (rplidar.launch)
# 2. 启动 cartographer_node (加载 rplidar_lds.lua)
# 3. 启动 cartographer_occupancy_grid_node (生成 /map)

# 观察 RViz
rosrun rviz rviz -d /home/abot/catkin_ws/src/abot_project/abot/rviz/cartographer.rviz

8.4 启动文件依赖关系图

bringup.launch 前置启动（底盘 + IMU + EKF）。 lidar_slam (gmapping) → lidar_slam.launch → gmapping | cartographer → cartographer_slam.launch → lua | 自动探索 → auto_slam.launch → gmapping+explore_lite+move_base ⚠️ 建图时必须关闭 AMCL（localize.launch），否则两个节点同时发 map→odom 导致 tf 冲突
