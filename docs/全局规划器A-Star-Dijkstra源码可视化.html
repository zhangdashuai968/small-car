核心理念：全局规划 = 在 2D costmap 上计算 potential 场（导航函数），然后沿梯度下降提取路径。Dijkstra（默认）用桶优先级队列实现 O(1) 入队，A* 用小顶堆 + 曼哈顿启发加速搜索。最终由 TEB 局部规划器执行。

🪣 三、Dijkstra 算法 — 桶优先级队列（默认）

核心创新：不用传统的二叉堆 (O(log n) per push)，而是用 3 个固定大小的桶 (PRIORITYBUFSIZE=10000) 实现 O(1) 入队。按 threshold_ 分层：低 cost 格子进 current 桶，中等进 next 桶，高的进 over 桶。当前层处理完后阈值递增，桶轮换。

⭐ 四、A* 算法 — 小顶堆 + 曼哈顿启发

⚖️ 五、Dijkstra vs A* 深度对比

维度 DijkstraExpansion (默认) AStarExpansion
数据结构 3 层固定大小桶数组 (PRIORITYBUFSIZE=10000) · O(1) 入队 std::vector + push_heap/pop_heap · O(log N) 入队/出队
排序依据 按 potential 值分桶 (threshold_ 分层)，同层内 FIFO 按 f(n) = g(n) + h(n) 堆排序，g=potential, h=曼哈顿距离×neutral_cost
启发函数 无 — 纯 cost 驱动，等价于 A* 的 h(n)=0 曼哈顿距离: |Δx| + |Δy|，乘 neutral_cost_ = 50
搜索形状 从起点向外同心圆扩散（wavefront） 从起点向目标方向椭圆聚焦搜索
传播方向 从目标反向传播到起点（end→start），一次计算可多次查询 从起点正向搜索到目标，每次规划需重新计算
最优性 ✅ 保证最优（cost 非负时） ✅ 保证最优（启发函数可纳且单调）
提前终止 到达起点格子时终止 到达目标格子时立即终止
适用场景 需要多次查询（同一个 costmap 多个起点）、精确最优路径 单次快速规划、大范围稀疏地图
ABOT 是否使用 ✅ 默认启用 (use_dijkstra: true) ❌ 未启用（设 use_dijkstra: false 可切换）

🏗️ 七、makePlan() — 完整调用链

1
坐标转换 world → map
costmap_->worldToMap(wx, wy, mx, my)
如果 old_navfn_behavior=false（默认）：用 worldToMap() 保留子像素精度
如果 old_navfn_behavior=true：直接取整（经典行为）
2
清除起点障碍物标记
clearRobotCell(start, start_x_i, start_y_i)
将起点所在 costmap 格子设为 FREE_SPACE（机器人当前站在这里，不可能是障碍物）
3
初始化 potential 场
potential_array_ = new float[nx * ny]
分配整张地图大小的浮点数组 · 如有 outline_map 选项，沿地图边界画一圈障碍物
4
★ 核心: calculatePotentials()
planner_->calculatePotentials(costmap_->getCharMap(), start_x, start_y, goal_x, goal_y, nx*ny*2, potential_array_)
cycles = nx×ny×2（完整地图两轮，足够覆盖）
Dijkstra: 从目标出发，桶优先级队列 BFS 扩散
A*: 从起点出发，堆优先队列 + 曼哈顿启发搜索
返回 found_legal: true=到达目标, false=无路
5
清除终点周围
planner_->clearEndpoint(costmap, potential, goal_x_i, goal_y_i, 2)
将终点周围 5×5 区域的 cost 强制设为可通行，防止因亚像素误差导致路径无法到达终点
6
发布 potential 可视化 (可选)
if(publish_potential_) publishPotential(potential_array_)
将 potential 场发布为 OccupancyGrid，RViz 可视化显示搜索范围
7
梯度下降提取路径
getPlanFromPotential(start_x, start_y, goal_x, goal_y, goal, plan)
从目标坐标出发，每次选四邻域中 potential 最小的格子，逐步走到起点
得到逆序路径 → 反转 → 转世界坐标 → 添加朝向（OrientationFilter）
8
发布路径
publishPlan(plan) → 发布到 ~/plan topic
RViz 显示绿色全局路径线 · TEB 局部规划器订阅此路径作为 via-point 约束

📉 八、梯度路径提取 — GradientPath

总结：全局规划器 = costmap 作为输入 + calculatePotentials() 计算导航函数 + 梯度下降提取路径。 Dijkstra (桶队列) 是默认选择，因为一次计算可多次查询。A* 适合单次快速规划。 算法选择在 initialize() 中根据 use_dijkstra 参数决定， 所有参数通过 ROS dynamic_reconfigure 实时调整。
