🧮 三、惩罚函数 — TEB 的"语言"

所有约束都通过 penalties.h 里的函数转化为优化代价。这是 YAML 参数的第一落地点：

大白话：想象一堵软墙。b=0.8，ε=0.1。速度到 0.69 以下完全没事（误差=0）；到了 0.71 开始微微有惩罚（误差=0.01）；到了 0.9 惩罚=0.2。g2o 把这个误差平方后乘上 weight_max_vel_x=2，加到总代价里。优化器就拼命把速度拉回 0.71 以下。

// 连接: (pose_i, pose_{i+1}, ΔT_i)
void computeError() {
  // 位移转到机器人坐标系
  r_dx =  cosθ·Δx + sinθ·Δy;  // 前进分量
  r_dy = -sinθ·Δx + cosθ·Δy;  // 侧移分量

  vx = r_dx / ΔT;
  vy = r_dy / ΔT;
  ω  = Δθ / ΔT;

  // 三个惩罚通道:
  _error[0] = penalty(vx, -0.2, 0.8, 0.1);
  _error[1] = penalty(vy,  0.8, 0.0);
  _error[2] = penalty(ω,  1.2, 0.1);
}

← 对应 YAML: max_vel_x=0.8, max_vel_x_backwards=0.2, max_vel_y=0.8, max_vel_theta=1.2, weight_max_vel_x=2, weight_max_vel_y=1, penalty_epsilon=0.1

void computeError() {
  pose1 = vertices[0];
  pose2 = vertices[1];
  _error[0] = (pose2->pos - pose1->pos).norm();
  // = √[(x₂-x₁)² + (y₂-y₁)²]
}

// 代价 = weight_shortest_path × Σ ||dᵢ||²
// 推动弹性带走直线而非绕弯

← YAML: weight_shortest_path=5

🏗️ 六、buildGraph() — 图构建的完整调用链

1
AddTEBVertices()
把 TimedElasticBand 上的每个位姿 PoseSE2 创建一个 VertexPose（3DOF: x,y,θ）， 每个 ΔT 创建一个 VertexTimeDiff（1DOF: dt）。全部加入 g2o 优化图。
→ 固定起点和终点（如果配置了初始/终止速度）
2
AddEdgesVelocity()
全向底盘 → 创建 EdgeVelocityHolonomic（3维残差：vx,vy,ω）
差速底盘 → 创建 EdgeVelocity（2维残差：v,ω）
每条边连接 (pose_i, pose_{i+1}, ΔT_i)，共 n 条
3
AddEdgesAcceleration()
创建 EdgeAcceleration（3维残差：ax,ay,α）
超边：每条边连接 5 个顶点 (pose_{i-1}, pose_i, pose_{i+1}, ΔT_{i-1}, ΔT_i)
共 n-1 条。再加上起点/终点的 EdgeAccelerationStart/Goal
4
AddEdgesTimeOptimal()
创建 EdgeTimeOptimal（1维残差：Δt）
一元边，每条只连接一个 ΔT_i，共 n 条
残差直接 = ΔT_i，代价 = weight × ΔT_i²
5
AddEdgesShortestPath()
创建 EdgeShortestPath（1维残差：||d||）
每条边连接 (pose_i, pose_{i+1})，共 n 条
残差 = 两点欧氏距离
6
AddEdgesObstacles(weight_multiplier)
对每个障碍物，找到最近的 obstacle_poses_affected (=15) 个弹性带节点
每个节点创建一条 EdgeObstacle（1维残差：距离惩罚）
≤ n × 15 条边。weight_multiplier 用于自适应权重调整
7
AddEdgesViaPoints()
对每个途经点，找到弹性带上最近的节点
创建 EdgeViaPoint（1维残差：距离）
像弹簧把弹性带"拉"向全局路径
8
AddEdgesKinematics*() — 底盘相关
差速：AddEdgesKinematicsDiffDrive() → EdgeKinematicsDiffDrive（非完整约束+前进偏好）
阿克曼：AddEdgesKinematicsCarlike() → EdgeKinematicsCarlike（非完整+最小转弯半径）
全向：跳过！不添加运动学边（weight_kinematics_nh=0 时）
9
AddEdgesDynamicObstacles() + AddEdgesPreferRotDir()
动态障碍物边（实验性）+ 旋转方向偏好边（防振荡）
