## 第一章 机器人硬件介绍

### 1.1 硬件框架
机器人硬件采用STM32F1驱动板组成系统通信框架

### 1.2 主控制器
ROS控制器采用Jetson nano主控，运行Ubuntu18.04系统，安装有ROS机器人操作系统，ROS版本为Melodic版本。

### 1.3 底层驱动板
底层驱动板为自主研发的机器人驱动板，跟上层主控采用ROSSERIAL协议通信，驱动板MCU采用STM32F103RCT6芯片，板载MPU6050 IMU角速度陀螺仪传感器。

### 1.4 激光雷达
思岚A1/A2雷达，可实现12M测距范围，5.5HZ扫描频率，8000次/秒测量频率。

### 1.5 深度摄像头
RGBD深度摄像头，RGB是彩色图像，D是depth（深度图像），可用于空间三维点云重建、视觉SLAM、视觉导航避障等应用。

## 第二章 开箱使用说明

### 2.1 使用前准备工作
准备使用步骤流程：
1. 机器人先充满电（5-8小时，直到充电器显示绿灯）
2. 开机上电后，用HDMI线连接显示器与Jetson nano进入系统桌面，连接无线WIFI，记下主控的IP
3. 准备Windows系统电脑，安装ToDesk远程桌面软件（not essential）

```bash
# ToDesk安装步骤
# 1. 打开todesk官网 https://www.todesk.com，选择Linux版本
# 2. 选择立即下载，选择第二个arm64，点击所标网址下载
# 3. 下载完成后，找到下载文件所在的文件夹，右键打开终端，输入以下代码：
sudo apt-get install ./todesk-v4.7.2.0-arm64.deb
# 4. 安装完成后，输入ToDesk即可打开软件
```

### 2.2 网络环境说明
ROS基于局域网通信，请确保路由器设置成静态IP形式，主控系统和Windows系统电脑在同一个网段下。

## 第三章 ABOT ROS 源码文件说明

### 3.1 ABOT ROS 机器人文件结构说明
在用户主目录下，`catkin_ws`为主要ROS工作空间。

**主要源码包作用：**
- `imu_calib`: IMU校正源码
- `m-explore`: 未知区域探索-自动建地图包
- `robot_localization`: 非线性状态估计节点集合，融合多个传感器数据（里程计 IMU）
- `camera_umd`: USB普通摄像头驱动包
- `lidarrplidar`: 雷达驱动包、镭神16线雷达驱动包
- `abot_project`: ABOT核心源码包

**ABOT核心源码包内主要功能包：**
- `abot_follower`: 深度摄像头跟随包
- `abot_nav`: 角速度线速度校正包
- `abot_msgs`: 自定义消息类型
- `abot_kcf`: KCF跟随包
- `abot_object_detect`: 目标检测包
- `abot`: 里程计发布包
- `abot_lidar_follower`: 雷达跟随超声波跟随包
- `abot_pid`: PID反馈调节包
- `abot_line_follower`: 摄像头寻线包
- `abot_deep_learning`: 深度学习检测包
- `abot_ar_track`: AR跟随、二维码识别包
- `abot_model`: URDF模型包
- `abot_object_follower`: 目标跟随包
- `abot_tracker_servo`: 云台跟随包
- `abot_yolo_detection`: YOLOV4检测包
- `abot_slam_3d`: 3D视觉建图
- `abot_xarm`: 移动抓取包（配合ABOT移动抓取小车使用）

## 第五章 ROS 控制基础

### 5.1 键盘、PS2控制

**PS2手柄控制:**
- L1触发普通模式：左侧L1+左遥感（上下推）为前进后退，左侧L1+右遥感（左右推）为左右旋转
- L2触发全向轮模式：左侧L2+左遥感(上下推)为前进后退，左侧L2+右遥感（左右推）为横移

**键盘控制:**
```bash
# 启动底层连接
roslaunch abot bringup.launch

# 查看加载的话题
rostopic list

# 启动键盘控制
rosrun teleop_twist_keyboard teleop_twist_keyboard.py
```

**键盘控制基础:**
- 小写模式："i"前进，","后退，"j"与"l"是左转右转
- 大写模式（Holonomic mode全向轮模式）：用于麦轮、Omni全向轮

### 5.2 IMU自动校正
```bash
# 启动底层连接
roslaunch abot bringup.launch

# IMU校正
cd ~/catkin_ws/src/abot_project/abot/param/imu
rosrun imu_calib do_calib
```

### 5.3 角速度校正
```bash
# 启动底层连接
roslaunch abot bringup.launch

# 启动角速度校正
rosrun abot_nav calibrate_angular.py

# 打开可视化工具
rosrun rqt_reconfigure rqt_reconfigure
```

**角速度比例系数计算:**
- 情况1：小车停下后度数60度（实际转了370度）→ `anguler_scale = 370/360 = 1.028`
- 情况2：小车停下后度数40度（实际转了350度）→ `anguler_scale = 350/360 = 0.972`

### 5.4 线速度校正
```bash
# 启动底层连接
roslaunch abot bringup.launch

# 启动线速度校正
rosrun abot_nav calibrate_linear.py

# 打开可视化工具
rosrun rqt_reconfigure rqt_reconfigure
```

**线速度比例系数计算:**
- 小车走了1.1米 → `linear_scale = 1.1/1 = 1.1`
- 小车走了0.9米 → `linear_scale = 0.9/1 = 0.9`

## 第十二章 xArm 机械臂控制

### 12.1 基于xArm机械臂的运动学理论

**正向运动学Python实现:**
```python
import numpy as np
import sympy as sym
from sympy import pi

# DH表参数定义
d_1, a_1, a_2, a_3, a_4 = sym.symbols("d_1, a_1, a_2, a_3, a_4")
theta_1, theta_2, theta_3, theta_4 = sym.symbols("theta_1, theta_2, theta_3, theta_4")

# 坐标系变换
T01 = DH(0, 0, theta_1, d_1)
T12 = DH(-pi/2, a_1, theta_2, 0)
T23 = DH(0, a_2, theta_3, 0)
T34 = DH(0, a_3, theta_4, 0)
T45 = DH(0, a_4, -pi/2, 0)
T56 = DH(-pi/2, 0, 0, 0)

# 基坐标系到工具坐标系变换
T06 = T01 * T12 * T23 * T34 * T45 * T56
```

**目标跟踪（MeanShift算法）:**
```python
import cv2
import numpy as np

cap = cv2.VideoCapture(0)
ret, frame = cap.read()
r, h, c, w = 240, 100, 400, 160
track_window = (c, r, w, h)
roi = frame[r:r+h, c:c+w]
hsv_roi = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv_roi, np.array((0., 60., 32.)), np.array((180., 255., 255.)))
roi_hist = cv2.calcHist([hsv_roi], [0], mask, [180], [0, 180])
cv2.normalize(roi_hist, roi_hist, 0, 255, cv2.NORM_MINMAX)
term_crit = (cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 10, 1)

while(True):
    ret, frame = cap.read()
    if ret == True:
        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
        dst = cv2.calcBackProject([hsv], [0], roi_hist, [0, 180], 1)
        ret, track_window = cv2.meanShift(dst, track_window, term_crit)
        x, y, w, h = track_window
        img2 = cv2.rectangle(frame, (x, y), (x+w, y+h), 255, 2)
        cv2.imshow('img2', img2)
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break
    else:
        break

cap.release()
cv2.destroyAllWindows()
```
